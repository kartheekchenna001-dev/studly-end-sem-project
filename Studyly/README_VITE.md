# Studyly — React + Vite setup

The existing Studyly interface, styling, scripts, assets, and features are preserved. Vite is added as the development server and production build tool, and React / React DOM are declared as project dependencies.

## Requirements
- Node.js 18 or newer

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The existing application code remains intact; this setup does not rewrite the existing screens or convert the legacy application scripts into React components.
